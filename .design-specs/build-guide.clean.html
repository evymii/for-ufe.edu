How to develop these designs

Build guide & prompts

Use the boards to the left as the visual reference. Build in the order below, one page per prompt, and keep every page on the same tokens and components.

1 · Stack
  • Next.js (App Router) + TypeScript for routing, image optimization and server-rendered SEO.
  • Tailwind CSS with the tokens below mapped to the theme; CSS variables for light/dark.
  • Motion: CSS transitions first; Framer Motion for the carousel, drawer and lightbox; View Transitions API for route changes (fade out 120ms, in 240ms + 8px rise).
  • Data: licensed stats/schedule feed behind a typed API route; CMS (Sanity/Contentful) for news, photos, video, history.
  • Video: HLS player (hls.js or Mux). Tests: Playwright + axe.

7 · Page-specific engineering notes
  • Home: carousel autoplay 6s, pause on hover/focus, crossfade 600ms; video rail uses scroll-snap.
  • Leaders: tabs change a query param; bars animate width 500ms on data change.
  • History: parallax via transform on scroll (rAF, disabled for reduced motion); IntersectionObserver for card reveals and decade tab spy.
  • Schedule: timezone-aware dates; calendar built from the same data as the list.
  • Photos/Videos: lazy-load with blur-up; lightbox traps focus; video route updates URL with history.pushState.
  • Newsletter: server action posts to the email provider; optimistic success state.
  • Fan club: outbound product links open a licensed retailer in a new tab.
8 · QA checklist

Compare each page to its board at 1280 and 390 · all hover/focus states · keyboard-only run · prefers-reduced-motion · no horizontal scroll · image CLS = 0 · Lighthouse perf ≥ 90 · axe has no serious issues · licensed assets only (logos, photos, player data).
